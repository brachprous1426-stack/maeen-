## مكتبة الأثر
مكتبة خاصة عربية للمواد المقروءة والمسموعة ومتابعة الإنجاز.

### التشغيل المحلي
1. انسخ `.env.example` إلى `.env` وأدخل `GEMINI_API_KEY` و`SESSION_SECRET` وبيانات المدير. لا تشارك `.env`.
2. `npm install`
3. `npm run setup`
4. `npm run dev` ثم افتح `http://localhost:3000`.

رمز دخول المدير هو قيمة `ADMIN_ACCESS_CODE` في `.env` (قيمة البداية المقترحة `ADM123`؛ غيّرها قبل الاستخدام). يظل الرمز ظاهراً للمدير في إدارة الأعضاء.

### متابعة المجموعات
حساب المشرف المرتبط بأعضاء عبر `supervisorId` يرى رابط **مجموعتي** في المكتبة. تعرض الصفحة أسماء أعضاء مجموعته، وعدد الكتب والمواد المسموعة المكتملة، والطلبات المعلقة، وتفاصيل كل طلب أو إنجاز. لا تظهر له رموز الدخول أو أعضاء المجموعات الأخرى. ياسر الجوهر مدير كامل الصلاحيات مع بقائه مرتبطًا بمجموعة العزم، لذلك تظهر له أيضًا لوحة الإدارة ويمكنه اعتماد الطلبات وإدارة الأعضاء والمواد.

### تقارير الإنجاز
من لوحة الإدارة يمكن تنزيل تقرير عام أو تقرير مجموعة أو طالب بصيغتي Excel (`.xlsx`) وPowerPoint (`.pptx`). يستطيع المشرف تنزيل تقرير مجموعته أو أحد طلابه فقط. تُنشأ الملفات من قاعدة بيانات الموقع عند التنزيل؛ ولا يلزم تجهيز ملف Excel مسبقًا. يعرض Excel الملخص، والطلاب، وسجل الطلبات والإنجازات، ويضيف مقارنة المجموعات في التقرير العام. يقدم PowerPoint ملخصًا وقوائم مناسبة للعرض. تُحسب الكتب والمسموعات المكتملة من السجلات المعتمدة فقط؛ وتظهر الطلبات المعلقة والمرفوضة منفصلة. هذه ملفات تقارير لحظة التنزيل، وتحديث ملف منزّل لا يغيّر بيانات الموقع.

### لوحة الإنجاز
الرابط `/achievements` يعرض جميع أصحاب دور الطالب `USER`، بما فيهم أصحاب الرصيد صفر والحسابات المعطّلة، ويستبعد الإدارة والمشرفين. للقراءة ترتيب بحسب مجموع صفحات ملفات PDF المكتملة والمعتمدة، وللسماع ترتيب بالدقائق مع احتساب الثواني. كل مادة تحتسب مرة واحدة من سجل الإنجاز الفريد للطالب والمادة؛ لا تنشأ قيود يدوية عند الاعتماد، لذلك لا يتكرر الرصيد، وحذف الإنجاز يلغي قيمته تلقائيًا. جميع صفحات PDF بما فيها الغلاف والفهارس داخلة في الحساب.

يمكن للمدير تعديل صفحات أو دقائق أي طالب، وللمشرف طلاب مجموعته فقط: موجب للزيادة وسالب للنقصان. تبقى الإدخالات اليدوية القديمة محسوبة، وتظهر منفصلة عن الرصيد التلقائي؛ ويظهر الإجمالي صفرًا إذا تجاوز الخصم الرصيد، مع الاحتفاظ بقيمة الخصم كاملة في السجل. لوحة الترتيب تتحدث عند فتحها وكل ٣٠ ثانية، وتدعم البحث والتصفية بالمجموعة والمراكز المشتركة عند التعادل.

تُقرأ بيانات المصادر عند إضافة مادة أو تغيير رابطها. يعتمد استخراج PDF المباشر على رابط Drive متاح للتنزيل؛ إذا كان خاصًا يستطيع المدير رفع نسخة مطابقة من قسم «اكتمال بيانات المكتبة» لحساب صفحاتها فقط دون تخزين الملف. يستخرج YouTube مدة المقطع الواحد المرتبط؛ عناوين مثل «٢٠ مقطع» ليست مددًا ولا تدخل كدقائق. يمكن إدخال مدة دقيقة بصيغة `H:MM:SS` أو عدد الدقائق. لا تُخمَّن بيانات الملفات غير المتاحة، وتظهر إنجازاتها بانتظار استكمال المصدر، ثم تُضاف تلقائيًا لجميع من أتمّ المادة. تغيير رابط المصدر يلغي قياسه القديم إن تعذر قياس المصدر الجديد.

لتحديث المصادر العامة الناقصة: `node --env-file=.env --import tsx scripts/sync-media-metadata.ts`. يحفظ نسخة احتياطية للقيم قبل التعديل وتقرير النتائج في `prisma/backups`. للملفات الخاصة المستخرجة عبر اتصال Drive، يحتفظ `prisma/backups/pdf-page-counts.json` بعدد الصفحات ومعرّف كل ملف دون روابط تنزيل مؤقتة. اختبارات الحساب والصلاحيات: `node --import tsx --test src/lib/achievement-totals.test.ts`.

### النشر
على VPS: ثبّت Node.js، عيّن متغيرات البيئة، استخدم قاعدة بيانات SQLite على قرص دائم، ثم `npm install`, `npm run setup`, `npm run build`, `npm start` خلف HTTPS reverse proxy. نسخ احتياطي دوري لملف قاعدة البيانات مطلوب. على Railway استخدم volume دائم. Vercel serverless ليس مناسباً لملف SQLite المحلي الدائم دون تخزين/قاعدة بيانات خارجية. لا تعتمد على Gemini في التشغيل؛ توليد الصور محاولة بناء اختيارية وبدائل SVG مرفقة.
