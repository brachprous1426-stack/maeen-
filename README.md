## مكتبة الأثر
مكتبة خاصة عربية للمواد المقروءة والمسموعة ومتابعة الإنجاز.

### التشغيل المحلي
1. انسخ `.env.example` إلى `.env` وأدخل `GEMINI_API_KEY` و`SESSION_SECRET` وبيانات المدير. لا تشارك `.env`.
2. `npm install`
3. `npm run setup`
4. `npm run dev` ثم افتح `http://localhost:3000`.

رمز دخول المدير هو قيمة `ADMIN_ACCESS_CODE` في `.env` (قيمة البداية المقترحة `ADM123`؛ غيّرها قبل الاستخدام). يظل الرمز ظاهراً للمدير في إدارة الأعضاء.

### متابعة المجموعات
حساب المشرف المرتبط بأعضاء عبر `supervisorId` يرى رابط **مجموعتي** في المكتبة. تعرض الصفحة أسماء أعضاء مجموعته، وعدد الكتب والمواد المسموعة المكتملة، والطلبات المعلقة، وتفاصيل كل طلب أو إنجاز. لا تظهر له رموز الدخول أو أعضاء المجموعات الأخرى. ياسر الجوهر مدير كامل الصلاحيات مع بقائه مرتبطًا بمجموعة العزم، لذلك تظهر له أيضًا لوحة الإدارة ويمكنه اعتماد الطلبات وإدارة الأعضاء والمواد.

### تقارير الإنجاز
من لوحة الإدارة يمكن تنزيل تقرير عام أو تقرير مجموعة أو طالب بصيغتي Excel (`.xlsx`) وPowerPoint (`.pptx`). يستطيع المشرف تنزيل تقرير مجموعته أو أحد طلابه فقط. تُنشأ الملفات من قاعدة بيانات الموقع عند التنزيل؛ ولا يلزم تجهيز ملف Excel مسبقًا. يعرض Excel الملخص، والطلاب، وسجل الطلبات والإنجازات، ويضيف مقارنة المجموعات في التقرير العام. يقدم PowerPoint ملخصًا وقوائم مناسبة للعرض. تُحسب الكتب والمسموعات المكتملة من السجلات المعتمدة فقط؛ وتظهر الطلبات المعلقة والمرفوضة منفصلة. هذه ملفات تقارير لحظة التنزيل، وتحديث ملف منزّل لا يغيّر بيانات الموقع.

### النشر
على VPS: ثبّت Node.js، عيّن متغيرات البيئة، استخدم قاعدة بيانات SQLite على قرص دائم، ثم `npm install`, `npm run setup`, `npm run build`, `npm start` خلف HTTPS reverse proxy. نسخ احتياطي دوري لملف قاعدة البيانات مطلوب. على Railway استخدم volume دائم. Vercel serverless ليس مناسباً لملف SQLite المحلي الدائم دون تخزين/قاعدة بيانات خارجية. لا تعتمد على Gemini في التشغيل؛ توليد الصور محاولة بناء اختيارية وبدائل SVG مرفقة.
